⌨️ Speed Typing Tester
A fun and interactive web application to test and improve your typing speed and accuracy. Built with simplicity and performance in mind, this project helps users practice typing while tracking their Words Per Minute (WPM), accuracy, and progress.

🚀 Features
Real-time typing test: Calculates WPM and accuracy as you type.

Customizable test duration: Choose from different time intervals (e.g., 30s, 60s, 120s).

Error tracking: Highlights mistakes to help improve accuracy.

Responsive design: Works seamlessly on desktop, tablet, and mobile.

Lightweight & fast: Minimal dependencies for smooth performance.

🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript

Styling: Responsive CSS with custom themes

Logic: Vanilla JavaScript for speed and accuracy calculations
